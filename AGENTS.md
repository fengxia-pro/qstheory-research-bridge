# Agent Instructions

This repository contains a portable AI-agent skill.

When the user asks about Qiushi/Qstheory policy signals, Chinese national research priorities, NSFC topic selection, SCI paper angles, future industries, technology self-reliance, basic research, or policy-to-research translation:

1. Read `SKILL.md` first and follow it as the canonical workflow.
2. Read `references/source-map.md` when choosing Qstheory/Qiushi sources.
3. Read `references/output-templates.md` when formatting daily scans, article deep reads, NSFC translations, or SCI angle outputs.
4. Browse current Qstheory/Qiushi sources unless the user provides article text.
5. Answer in Chinese by default unless the user asks otherwise.

Do not treat `agents/openai.yaml` as required. It is optional metadata for OpenAI/Codex-style hosts.
